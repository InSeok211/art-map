# 그린하우스 외관 디자인 시안

`greenhouse-reference-sheet-v1.png`는 사용자가 지정한 [그린하우스 네이버 지도](https://naver.me/5A3Th1m6)의
외관 사진을 참고해 이미지 생성으로 만든 건축 참고 시안입니다. 확인한 주소는 부산 사하구 감내1로175번길 13, 1층입니다.

정면 전체, 사선 외관, 중앙 진입 계단, 창호·지붕, 벽화·수경 장식의 상세를 한 장에 담았습니다.
실측 도면이 아니며 일부 비례·세부는 생성 과정에서 달라질 수 있습니다.
CAD 모델링 시 원본 사진과 대조하고, 생성된 치수나 확인되지 않은 뒷면을 사실로 사용하지 않아야 합니다.

참고 사진은 [네이버 플레이스 사진](https://pcmap.place.naver.com/restaurant/1642794570/photo)에서 확인했습니다.
사진 촬영 시점에 따른 차이를 고려해 2026년 사진의 노란 진입 계단을 우선하고,
2023년 업체 사진은 전체 건물 구성 확인에 사용했습니다. 원본은 `.tmp/greenhouse-design/references/`에 보관합니다.
`front-2026.jpg`는 사진 목록 인덱스가 예상과 달라 실제로 실내 작품 사진이며 시안 생성 입력에서는 제외했습니다.
