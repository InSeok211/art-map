# 아름다운한글 외관 시안 01

이 시안은 사용자가 제공한 위치도와 외관 사진 4장을 바탕으로 만든 지도용 3D 모델이다. 유리 안쪽의 서예·액자 작품은 작가의 저작물이므로 사진을 모델에 넣지 않고 종이 색 단색 면으로만 표시한다(`PAPER_COLORS`). 사진에서 잘라 냈던 원본과 사진 기반 참고 이미지는 지웠다.

## 사진에서 확인되는 요소

- 복층 공간의 긴 전면과 앞으로 길게 나온 얇은 처마
- 검은색 세로 창틀로 나뉜 통유리, 상단의 격자 장식
- 유리 안쪽에 걸린 한글 서예 작품과 체험 안내지
- 전면 왼쪽의 낮은 나무 난간과 액자 작품
- 오른쪽 끝의 바깥으로 열린 유리 출입문과 따뜻한 목재 내부
- 출입구 앞 청록색으로 칠한 바닥과 경사진 골목

## 모델링 시 추정으로 취급할 요소

- 사진에 모두 드러나지 않는 지붕 경사와 측면 마감
- 위치도만으로 알 수 없는 실제 벽 길이와 깊이
- 작품 글씨와 안내 문구의 내용(모델에는 넣지 않음)

건물 외곽은 첨부 위치도의 필지 방향을 우선으로 맞추고, 사진에 보이는 전면을 골목 쪽에 배치한다.

## 3D 시안

- 생성 스크립트: `scripts/build-beautiful-hangul.mjs`
- 모델 파일: `src/assets/models/custom/beautiful-hangul-studio.glb`
- 미리보기: `beautiful-hangul-preview.html`
- 모델링 기준 크기: 출입문 높이 약 2.42 m(사용자가 추정한 2~2.5 m 범위), 전면 약 8.8 m, 깊이 약 11 m, 처마 높이 약 4.1 m. 처마를 포함한 전체 깊이는 약 13.2 m다. 사진만으로 실제 치수를 확정할 수 없어 비율은 시안용 추정이다.
- 지도 모델 목록에는 등록했으며, 실제 지도 좌표와 회전은 아직 지정하지 않았다.
