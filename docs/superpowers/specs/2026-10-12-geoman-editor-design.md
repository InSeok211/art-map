# Geoman 기반 공방 배치·도로 편집 설계

작성일: 2026-10-12
상태: 사용자 검토용 설계. 제품 코드와 운영 데이터는 아직 변경하지 않음.

## 목적

관리자가 감천 지도에서 업로드한 공방 GLB의 위치를 정밀 조절하고, 기존 OSM 도로와 직접 추가한 골목길을 같은 편집 화면에서 수정한다. 공개 화면과 길찾기는 관리자가 공개한 수정본을 사용한다.

## 합의된 범위

- 대상: 업로드한 GLB 모델, 기존 도로·골목·계단, 직접 추가한 골목길.
- 모델: 이동, 10cm·50cm·1m 미세 이동, 숫자 좌표 입력, 회전, 크기, 지면 기준 높이 보정.
- 길: 선택, 중심선 점 이동·추가·삭제, 길 전체 이동, 폭 입력, 보행로/계단 설정, 연결점 맞춤.
- 공통: 원래 위치 비교, 대상별 원위치 복원, 실행 취소·다시 실행, 초안 저장과 명시적 공개.
- 실제 지도 좌표와 미터 단위 사용. 지도 확대율에 따라 저장 정밀도가 바뀌지 않는다.

## 도구 선택

도로의 그리기·꼭짓점 편집·드래그·회전·맞춤에 `@geoman-io/maplibre-geoman-free`를 사용한다. 설치 시 배포 버전과 MapLibre 6 호환성을 확인하고 검증한 버전을 lockfile로 고정한다. 유료판과 유료 기능은 사용하지 않는다.

Geoman 무료판의 내장 실행 취소/다시 실행과 확장 선택 기능에 의존하지 않는다. 대상 선택은 기존 MapLibre 레이어 클릭과 목록을 사용하고, 실행 취소는 앱의 편집 이력으로 구현한다. GLB는 Geoman의 3D 객체가 아니므로 기존 Three.js 배치 코드와 별도 이동 손잡이·숫자 패널로 조절한다.

공식 참고: https://geoman.io/docs/maplibre

## 화면과 조작

`/studio/`에 모델/길 편집 전환과 평면/3D 확인 전환을 둔다.

1. 평면 화면에서 목록 또는 지도 객체를 눌러 대상을 선택한다.
2. 모델은 위치 손잡이 또는 숫자로 움직인다. 길은 점 편집/전체 이동 모드를 고른다.
3. 변경을 즉시 평면 지도에서 확인한다. 모델 배치와 길의 3D 결과도 확인할 수 있다.
4. 초안 저장은 편집 화면에만 반영된다. 공개하기가 성공한 뒤 공개 지도와 길찾기에 적용된다.

원본 선은 비교용 점선으로 표시한다. 격자는 선택적으로 켜는 보조 도구다. 새 길 그리기와 모델 이동 중에는 일반 지도 선택 이벤트가 중복 실행되지 않게 한다. 편집 종료 시 이벤트·Geoman 소스·도구를 정리한다.

모델 위치는 `streetCoordinates.ts`의 동쪽/남쪽 미터 좌표와 경도·위도를 변환한다. 회전은 0.1도, 이동은 0.1m 단위로 입력할 수 있다. 지면 높이 보정은 별도 필드로 저장하며 예전 모델 데이터의 기본값은 0m다.

## 저장 형식과 호환

기존 도로 파일 `src/data/street-surfaces.json`을 직접 수정하지 않는다. OSM 도로 ID로 수정 내용을 연결한다.

길 수정 데이터는 기존 도로 ID별 중심선·폭·종류·숨김 상태의 override와 추가 골목길 목록으로 구성한다. 기존 도로를 복원하면 해당 override를 제거한다. 원본 ID와 사용자 생성 ID는 다른 네임스페이스를 사용한다.

기존 `map_alleys`와 건물 초안/공개본을 삭제하지 않고 새 길 초안/공개 저장소를 추가한다. 첫 도입 시 기존 공개 골목길을 보존해 초기 공개본과 초안의 기준으로 사용한다. GPX 기록과 버린 후보는 관리자 데이터로 유지한다. 이전 API와 편집 경로가 새 저장본을 덮어쓰지 않도록 호환 처리를 같이 구현한다.

길 변경은 자동으로 공개되지 않는다. 서버 저장 실패 시 화면에 미저장 상태를 남기며, 서버 편집 화면에서 실패한 값을 로컬 저장 성공으로 표시하지 않는다. 공개 전에 초안 저장 완료를 기다린다. 초안이 낡은 경우 충돌을 안내하고 최신본을 다시 불러오도록 한다.

## 3D와 길찾기 연결

하나의 도로 합성 함수가 원본 + 기존 도로 override + 추가 골목길을 결합한다. 편집 미리보기와 공개 화면·길찾기가 각각 같은 초안/공개본을 통해 이 함수를 사용한다. 삭제하거나 옮긴 길이 원래 위치의 길찾기 그래프에 남지 않는다.

길 끝점이 선분 중간에 연결되면 연결점에 노드를 만들어 실제 그래프도 이어지도록 한다. 모든 선 교차를 연결로 취급하지 않고 명시적으로 맞춘 연결과 원본 공통 노드를 보존한다. 계단 유형은 계단 피하기 옵션에 반영한다.

현재 3D 도로 바닥은 사전 생성된 저장본이다. 수정이 없는 경우 이를 그대로 사용한다. 수정본이 있는 경우 해당 도로를 반영한 도형을 백그라운드 작업으로 계산하고 입력 키로 캐시한다. 포인터를 움직일 때마다 마을 전체 도형을 다시 계산하지 않는다. 편집 완료 시 새 도형을 준비한 뒤 교체하며, 원래 도로 바닥이 중복으로 남지 않는지 검증한다.

모델 또는 길 이동이 주변 건물과 겹치면 확인할 수 있도록 표시한다. 길을 이동했다고 주변 건물을 임의로 이동시키지 않는다.

## 적용 순서

1. Geoman을 관리자 화면에서만 불러오고, 현재 MapLibre 생성·종료 흐름과 연결한다.
2. 원본 도로/추가 골목길의 ID 변환, 선택·편집·검증과 앱 이력을 구현한다.
3. 길 초안/공개 저장과 기존 골목길 데이터 호환을 구현한다.
4. 도로 합성 결과를 평면 표시, 3D 바닥, 길찾기에 연결한다.
5. 기존 GLB 배치 패널에 미세 이동·숫자 입력·높이 보정과 원위치 복원을 추가한다.
6. 테스트·빌드·브라우저 검증 후 GitHub 반영과 운영 배포를 진행한다.

## 완료 검증

- 기존 길과 추가 길을 편집·저장·재접속해도 경로와 폭이 유지된다.
- 새로고침·탭 전환·지도 스타일 재로딩 후에도 중복 도구나 이벤트가 생기지 않는다.
- 지도 경계 밖으로 이어진 원본 도로의 외부 구간을 보존하고 내부 구간만 편집한다.
- 잘못된 좌표·유효하지 않은 ID·너무 짧은 선은 저장하지 않는다.
- 실행 취소가 드래그 한 번을 한 작업으로 취급한다.
- 모델의 미세 이동·회전·크기·높이가 저장과 공개 후 동일하다.
- 저장 전/초안 상태가 공개 지도에 노출되지 않는다.
- 공개 후 변경한 길이 3D 표시와 길찾기에 일치한다.
- 기존 공개 골목길, 모델 파일, 관리자 GPS 기록을 보존한다.
- 기존 테스트와 추가 기능 테스트, 앱 빌드가 통과한다.

## 검토 결과

원하는 모델 배치와 모든 길 편집을 포함한다. Geoman의 도형 편집 역할과 앱의 모델·저장·3D·길찾기 역할을 구분했다. 무료/유료 기능의 경계를 확인했다. 원본 보존·초안 공개·기존 데이터 호환·느린 도형 계산의 처리 기준을 포함했다.
