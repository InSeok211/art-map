# 도미도 외관 복원 시안

## 디자인 시안 기반 상세 버전

`design/domido-exterior/domido-reference-sheet-v1.png`를 참고해 별도의 상세 버전을 만들었습니다.

```powershell
npm run build:domido-design
```

출력은 `.tmp/domido-design/domido-design.glb`, `domido-design.usda`, `domido-design.mesh.json`입니다.
미리보기는 `http://127.0.0.1:5173/.tmp/domido-design/preview.html`이고,
정면·사선·입구 확대 버튼 및 디자인 시안 링크가 있습니다. 이전 사진 기반 버전은 `.tmp/domido/`에 유지됩니다.

추가한 CAD 요소는 이중 창틀·가느다란 유리살·문 상부의 실제 개구부·문선·하부 문 패널,
차양 옆판과 하부 마감·조명·처마 홈통·반원 난간과 장식 고리·창구 몰딩입니다.
형상은 CAD 커널에서 제작하며, 표면 재질과 호랑이 벽화는 원본 생성 시안 이미지의 영역을 UV로 연결합니다.
이미지 자체를 잘라 바꾸거나 외벽 사진 전체를 평면으로 붙이는 방식은 사용하지 않았습니다.
간판·벽화·목재/벽면 재질은 GLB에 포함되며 USD는 CAD 메시와 부품 색을 담습니다.

CAD 부품 347개가 manifold 검사를 통과했고 CAD 삼각형은 35,532개입니다.
최종 GLB는 6,624,032바이트이며 기존 지도 업로드 검사기를 통과했습니다.
기본 폭·깊이·높이는 이전 모델과 같은 추정값입니다. 생성 시안의 디테일도 실제 사진과의 대조가 필요합니다.

공개 지도에 자동 배치하거나 기존 건물을 교체하지 않습니다.

## 재현 범위와 추정값

사진에서 보이는 낮은 왼쪽 매장과 높은 오른쪽 매장, 목재 창호 3구획,
초록색 골 차양, 목재 박공 출입구와 기둥, 서비스 창구, 갈색 지붕 가장자리,
은색 원형 장식 난간, 녹색 입구 조명을 재현했습니다.
`cafe Domido` 간판은 새로 렌더링한 글자이고, 파란 호랑이는 직접 그린 단순화 벡터 그래픽입니다.
사진 픽셀을 외벽에 붙이지 않았습니다. 벽화의 원작 세부와 글꼴·색은 동일하지 않습니다.

실측 자료가 없으므로 문 폭 약 0.96m를 비례 기준으로 가정했습니다.
외벽 전체 폭 9.40m, 건물 깊이 4.40m, 왼쪽 지붕 높이 4.75m,
오른쪽 지붕 높이 5.50m, 도로 측 출입 바닥 높이 약 1.8m가 모델링 입력값입니다.
뒷면과 측면의 확인되지 않은 부분은 단순한 벽으로 닫았습니다.
실내 테이블·장비는 창 너머에 보이는 분위기를 위한 단순 형상이고 실측 배치가 아닙니다.
미리보기의 경사 도로는 추정한 문맥 표현이며 건물 GLB에 포함되지 않습니다.

## 다시 생성하고 지도에 사용하기

```powershell
npm run build:domido
```

USD BRep 설치·빌드는 [설치 안내](USD_BREP_BUILDINGS.md)를 따릅니다.
간판·벽화 래스터화에는 로컬 Codex 런타임의 `@napi-rs/canvas`를 사용합니다.
이 PC의 모듈 위치는 Git에서 제외된 `.tmp/brep-dependencies.json`에 저장되어 있습니다.
다른 환경에서는 `@napi-rs/canvas`를 사용할 수 있게 설치하거나 그 설정의 `canvasModule`을 모듈 경로로 지정합니다.
글자는 Windows Georgia Bold를 사용합니다.

결과 파일은 `.tmp/domido/domido.glb`, `domido.usda`, `domido.mesh.json`입니다.
USD와 메시 JSON은 CAD 부품을 담고, 최종 GLB에는 간판·벽화 그래픽도 포함됩니다.
미리보기: `npm run dev` 후 `http://127.0.0.1:5173/.tmp/domido/preview.html`.
GLB는 지도 편집기의 건물 모델 라이브러리에 올려 위치·방향·크기·고도를 조정할 수 있습니다.
지도에 놓을 때에는 주변 지형 고도와 별도로 모델의 진입 바닥 높이를 맞춰야 합니다.

## 검증

CAD 부품 254개의 manifold 검사를 통과했습니다.
벽·문·창구는 BRep 차집합, 박공과 트림은 닫힌 윤곽의 선형 sweep,
난간은 CAD 원통·구·토러스로 제작하고 커널에서 테셀레이션했습니다.
CAD 삼각형은 20,852개입니다. 같은 재질의 부품은 묶어 지도 렌더링 부담을 줄였습니다.
최종 GLB는 기존 지도 업로드 검사기를 사용해 외부 파일 참조와 지원하지 않는 압축 형식을 검사합니다.
검증한 최종 GLB 크기는 1,658,436바이트이며, 브라우저에서 텍스처·모델 로딩과 렌더링을 확인했습니다.
