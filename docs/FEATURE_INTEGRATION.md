# 최신 커밋에 기존 기능 통합

기준 커밋: `de7f8dd` (origin/main). 작업 브랜치: `integrate/local-editor-20261012`.
이 문서는 2026-10-12 사용자 선택과 실제 적용 범위를 기록합니다.

## 선택 기준

1. 최신 개발자의 기능별 폴더, 공개 지도(`/`), 편집 앱(`/studio/`), API(`/api/`) 구조를 유지합니다.
2. 기존에 만든 건물 편집과 지형 기능은 공통 건물 형식에 추가합니다. 별도 평지/지형 DB를 만들지 않습니다.
3. 운영 공개본은 서버 D1/R2에서 관리합니다. ZIP은 로컬 프로젝트 백업과 복원에 사용합니다.
4. 사용자 지도에는 건물 ID 편집 메뉴와 3D 클릭 선택용 정점 데이터를 만들지 않습니다. 데이터 연결용 ID는 유지합니다.
5. 개발자가 제거한 GPS 자동/수동 기록과 예전 독립 3D 배치 탭은 다시 추가하지 않습니다. GPX 가져오기는 유지합니다.

## 기능별 결정

| 기능 | 결정 | 적용 위치·이유 |
|---|---|---|
| 기능별 파일 분리 | 유지 | 최신 `src/`, `server/`, `migrations/` 구조 사용. 별도 지도 Worker는 없애고 홈페이지 서버 하나로 합침(`npm run export:site`) |
| 같은 재질 GLB 부품 합치기 | 유지 | 최신 `src/scene/mergeModel.ts`; 모델 배치와 함께 사용 |
| 경사 지형 기반 일반 건물 생성 | 포함 | `src/scene/terrain/terrainBuildingGeometry.ts`; 벽 밑단은 경사면, 층·지붕은 수평 |
| GLB 지면 맞춤과 기초 벽 | 포함 | `src/scene/terrain/buildingFoundation.ts`, `placedModels.ts` |
| 건물 ID 선택·검색·이름 | 포함 | `buildingPicking.ts`, `useBuildingEditing.ts`, `BuildingEditor.tsx` |
| 건물 이동·회전·크기·복제 | 포함 | `buildingSettings.ts`, `BuildingProperties.tsx`; 원본 OSM 윤곽과 배치 설정 구분 |
| 평지 높이와 지형 고도 설정 | 포함 | `flatBaseMeters`, `terrain`; 데이터는 공통, 높이 설정은 별도 |
| 출입구 기준 고도·자동 맞춤 | 포함 | 지면 추정값을 관리자 수동 보정 가능 |
| 실행 취소·다시 실행 | 포함 | `editHistory.ts`, `buildingEditStore.ts`; 건물 초안에만 최대 100단계 |
| 로컬 프로젝트 ZIP 백업·복원 | 포함 | `LocalWorkspaceTools.tsx`, `workspaceFiles.ts`, `projectArchive.ts`; GLB 포함 |
| 읽기 전용 로컬 공개 미리보기 | 포함 | 개발 서버의 `/`가 브라우저 공개본과 현재 골목을 읽음 |
| 서버 공개 지도 | 기본 방식 | `/studio/`의 공개하기가 D1 공개본을 갱신하고 사용자 GLB는 R2 사용 |
| 새 정적 공개 ZIP 내보내기·snapshot 게시 | 제외 | 사용자 선택: 서버 공개를 기본으로 단일 운영 경로 유지 |
| 예전 공개 ZIP 복원 | 호환 유지 | 이미 내려받은 데이터의 복구에 사용; 새 게시 기능은 제공하지 않음 |
| GPS 자동/수동 기록·주머니 모드 | 제외 | 최신 개발자의 삭제 결정 유지; GPX 가져오기는 가능 |
| 공방·그린하우스·아름다운한글 전용 모델 일반 편집 | 보류 | 전용 외관 유지; 일반 건물과 사용자 GLB만 편집 |
| D1/R2 전체 백업·ZIP의 서버 직접 복원 | 보류 | 이번 ZIP은 로컬 편집기 자료만 다룸. 서버 데이터 복원·파일 ID 이전은 별도 작업 |
| 건물 전체 렌더러 추가 분할 | 보류 | 기능 통합 범위에 집중. 큰 파일 분리는 후속 작업 |

## 통합 시 함께 수정한 연결 오류

- 개발 서버의 공개 지도도 로컬 공개본을 읽습니다. Worker 빌드에서는 localhost에서도 서버 API를 사용합니다.
- 골목 서버 조회가 실패하면 편집 앱을 멈추고 오류와 새로고침 버튼을 표시합니다. 서버 저장 안내와 로컬 저장이 섞이지 않습니다.
- 빈 서버에 기존 브라우저 골목을 자동 게시하는 경로를 제거했습니다. 로컬 자료의 서버 이전은 명시적인 별도 작업입니다.
- 건물 API는 `draft`가 없는 요청, 잘못된 목록, 삭제되는 유효하지 않은 항목, 중복 ID를 거절하여 기존 초안을 보존합니다.
- 서버가 클라이언트와 같은 `sanitizeBuildingEdits`/`sanitizeBuildingSettings`를 사용하므로 이름·배치·평지 높이·지형 설정이 저장과 공개 과정에서 유지됩니다. 기존 JSON 컬럼을 사용하므로 별도 DB 마이그레이션은 필요하지 않습니다.

## 데이터와 배포 범위

코드 통합은 기존 브라우저의 건물 초안·공개본·모델 파일을 삭제하지 않습니다. 기존 localStorage/IndexedDB 키를 유지합니다.
로컬 편집기 데이터가 D1/R2로 자동 업로드되지는 않습니다. 서버용 로그인 설정, 실제 데이터 이전, 운영 배포는 별도 단계입니다.
로컬 복구본은 Git stash `local-editor-before-latest-integration-20261012`로 보관했습니다.
