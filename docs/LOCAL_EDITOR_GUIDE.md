# 로컬 지도 편집기 1차 사용 설명

지도 편집 앱(`/studio/`, 홈페이지에서는 `/map-app/studio/`)에서 사용하는 건물 편집 기능입니다. Vite에서는 브라우저에 저장하고, 홈페이지에서는 운영자 로그인 후 홈페이지 D1/R2에 저장합니다. 기능 포함·제외 결정은 [FEATURE_INTEGRATION.md](FEATURE_INTEGRATION.md)에 있습니다.

## 화장실·버스 정류장 등 장소 수정

편집기의 **장소** 메뉴에서 화장실·버스 정류장을 선택한 다음 **선택 장소 수정**을 누릅니다. 이름·분류·주소·설명을 바꾸고, 지도 안쪽을 클릭해 위치를 옮길 수 있습니다. **장소 추가**와 수정 양식의 **삭제**도 지원합니다.

양식의 **저장**을 누른 뒤 화면 상단의 **장소 공개하기**를 눌러야 공개 지도에 반영됩니다. 저장 실패 시 안내가 표시되고 다시 시도할 수 있습니다. 홈페이지에서는 관리자만 저장할 수 있으며 D1에 보관됩니다. 개발 미리보기에서는 같은 브라우저에 저장됩니다. 공방 건물 정보는 기존 **건물** 메뉴에서 관리합니다.

## 시작

`art-map/`에서 `npm run dev`를 실행하고 `http://127.0.0.1:5173/studio/`의 **건물** 메뉴를 엽니다. 기존 서버가 실행 중이면 브라우저에서 바로 확인합니다.

## 편집 화면

상단의 저장 상태·공개하기(로컬에서는 공개본 확정)·초안 버리기·실행 취소는 속성 목록을 스크롤해도 항상 보입니다. 수정 내용은 기존처럼 초안에 자동 저장됩니다.

지도에서 대상을 고르면 이름과 ID 아래에 **배치**가 먼저 열립니다. **지형과 고도**(평지에서는 바닥 높이), **외관**, **장소 정보**, **3D 모델 교체**는 제목을 눌러 펼칩니다. 일반 건물에는 외관, 작가님 공방에는 장소 정보, 사용자 GLB에는 모델 위치·방향·크기 속성이 나옵니다. **닫기**로 선택을 해제합니다.

**대상 찾기**에는 기존 건물 ID 검색과 고친·추가한 대상 목록이 있습니다. 새 모델은 대상을 선택하지 않은 상태의 **3D 모델 추가**에서 올리거나 배치합니다. 로컬 백업·복원·공개본 미리보기는 **백업과 미리보기**에 있습니다.

다른 대상을 선택하면 속성 목록이 위로 돌아가 배치가 먼저 열립니다. 같은 대상의 값을 저장할 때는 펼친 그룹과 스크롤 위치를 유지합니다.

## 건물 선택과 배치

1. 지도에 보이는 건물의 벽·지붕 또는 바닥 윤곽을 클릭합니다. 병합된 3D 도형에서도 원래 건물 ID를 찾아 선택합니다.
2. 패널에서 **선택 ID**를 확인합니다. 기존 건물 번호는 검색창에 입력해 바로 찾을 수도 있습니다.
3. 건물 이름을 입력하고 입력칸을 벗어나면 저장됩니다.
4. 지도 위 **이동·회전·크기** 손잡이를 드래그합니다. 끄는 동안 손잡이에 이동 거리·각도·폭(건물은 크기 %)이 보이고, 회전 원과 긴 쪽 축이 안내선으로 나옵니다. 3D 모델은 끄는 대로 바로 따라오고, 건물은 옮긴 뒤의 윤곽이 주황 점선으로 미리 보입니다. 회전은 15° 배수 근처(±4°)에서 그 각도에 맞춰집니다. 손을 놓을 때 한 번 저장하므로 실행 취소 한 번으로 되돌릴 수 있습니다(`src/buildings/transformHandles.ts`, `src/map/handleGuide.ts`).
5. 정확한 값은 경도·위도·회전·배율 또는 모델 폭 입력칸에 입력합니다. Enter 또는 입력칸을 벗어날 때 적용합니다.
6. **지도에서 위치 옮기기**를 누른 뒤 새 위치를 클릭할 수도 있습니다. Esc로 취소합니다.
7. **건물 복제** 또는 **모델 복제**로 같은 설정의 복사본을 만듭니다. 원본에서 약 2m씩 동쪽·남쪽으로 이동한 위치에 놓습니다.

원본 OSM 윤곽은 유지하고, 배치 설정을 별도로 저장합니다. 직접 추가한 건물은 `b-…`, 사용자 GLB 배치는 `p-…` ID를 사용합니다. 이동·크기 조절로 일반 건물 윤곽이 지도 범위를 벗어나면 적용하지 않습니다.

공방·그린하우스·아름다운한글 기본 전용 모델은 기존과 같이 일반 건물 편집에서 변경하지 않습니다. 사용자가 업로드한 GLB는 배치·크기·방향·고도 조절과 복제를 지원합니다.

## 평지와 3D 지형 높이

**평지 편집**에서는 평지 바닥 높이를 조절합니다. **3D 지형 편집**에서는 다음 값을 조절합니다.

| 항목 | 의미 |
|---|---|
| 지형 높이 보정 | 자동 또는 직접 정한 기준 층에 더하는 상대 높이(m) |
| 기준 층 해발고도 | 기준 층의 절대 고도(m). 입력칸을 비우면 자동 계산 |
| 출입구 위치 지정 | 지도에서 출입구가 닿는 지면을 지정해 자동 고도의 기준으로 사용 |
| 지면 자동 맞춤 | 해당 건물의 수동 지형 설정을 지우고 자동 배치로 복귀 |
| 기초 벽 연결 | 사용자 GLB를 선택했을 때 낮은 쪽 틈을 기초 벽으로 연결하는 설정 |

일반 건물은 경사면에서부터 벽을 생성합니다. 별도 기초 없이 벽 자체가 지면까지 이어지므로 기초 체크박스는 사용자 GLB에만 표시합니다. 기본 전용 모델은 위 표의 편집 대상에 포함되지 않습니다.

일반 건물에는 자동 계산한 기준 층과 외곽 지면의 고도 범위를 표시합니다. GLB에는 모델 중심 위치의 지면 고도를 표시합니다. GLB 중심 지면 수치는 모델 전체의 실제 바닥 배치 고도와 같다고 보장하지 않습니다.

화면에서 바닥과 지형의 겹침을 줄이려고 약 0.35m의 표현용 높이를 사용합니다. 일반 건물의 고도 안내에서는 이 값을 제외합니다. 고도는 8m 격자 DEM의 보간 추정이며 실측값이 아닙니다. 직접 정한 낮은 기준 고도에서는 높은 쪽 벽이 지형에 묻힐 수 있습니다.

건물 이름·위치·색·높이는 공통 데이터입니다. 평지 바닥 높이와 3D 지형 설정은 각각 별도 필드에 저장합니다. 일반 건물 배치를 바꾸면 기존 출입구 지점은 지우고 자동 출입면 계산으로 되돌립니다.

## 저장과 실행 취소

Vite 로컬 편집기는 건물 초안을 localStorage, 사용자 GLB를 IndexedDB에 저장합니다. 서버 편집 앱은 초안·공개본을 D1, 사용자 GLB를 R2에 저장합니다. 저장 실패는 상태 메시지로 표시합니다.

- **실행 취소:** Ctrl+Z. Mac 키보드는 Command+Z.
- **다시 실행:** Ctrl+Shift+Z 또는 Ctrl+Y.
- 입력칸에서 타이핑 중에는 입력칸의 기본 편집 동작을 유지합니다.
- 새 윤곽을 그리는 중 Ctrl+Z는 마지막 점을 지웁니다.
- 같은 속성을 연속 조절하는 변경은 묶어서 취소합니다. 건물 초안 기록은 현재 세션에서 최대 100단계 보관합니다.
- 실행 취소로 복구할 수 있는 GLB 파일은 파일 삭제 목록에서 보호합니다.

실행 취소는 **건물 초안**을 대상으로 합니다. 골목 편집, 파일 업로드·삭제, 공개본 변경을 모두 되돌리는 기능은 아닙니다. 세션을 종료한 뒤 복구하려면 프로젝트 백업을 사용합니다.

## 백업과 공개본

| 버튼 | 결과 |
|---|---|
| 프로젝트 백업 ZIP | `project.json`과 사용자 GLB. 건물 초안·공개본·현재 골목 목록·모델 파일 메타데이터 포함 |
| 백업 불러오기 | 이 편집기가 만든 프로젝트 백업 또는 과거 공개 ZIP을 검사한 뒤 로컬 데이터에 복원 |
| 공개본 확정 | 현재 건물 초안을 이 브라우저의 공개본으로 확정 |
| 사용자 지도 미리보기 | 편집 상태를 유지한 채 화면 안에서 읽기 전용 공개 지도 열기. 닫기 버튼 또는 Esc로 돌아오기 |

ZIP 백업은 로컬 개발 편집기에서만 제공합니다. 서버에서는 **공개하기**로 건물 공개본을 반영합니다. 건물 ID는 데이터 연결용으로 유지하며 사용자 지도에는 편집 메뉴와 3D 클릭 선택용 정점 데이터를 만들지 않습니다.

GLB는 내장 텍스처를 함께 포함합니다. ZIP은 추가 압축을 하지 않는 표준 저장 방식입니다. 백업 묶음은 최대 200MB·파일 110개, 복원하는 모델 목록은 최대 100개, GLB 하나는 기존과 같이 20MB까지 지원합니다. 손상된 파일·유효하지 않은 건물 데이터·빠진 모델 파일·잘못된 경로를 발견하면 복원을 중단합니다.

백업은 현재 로컬 모델 목록 전체를 포함합니다. 기존 지도 입력 자료·기본 전용 모델·지도 실행 JS/CSS는 원본 프로젝트와 앱 빌드에서 관리합니다. ZIP에 홈페이지 전체 코드나 D1/R2 전체 자료가 들어 있지는 않습니다.

프로젝트 백업을 불러오면 건물 초안·공개본·골목 목록을 복원합니다. 기존 공개 ZIP을 불러오면 해당 공개 데이터를 초안과 공개본 모두에 적용합니다. 복원 후 건물 초안은 실행 취소할 수 있지만 공개본·골목·모델 파일까지 함께 되돌리지는 않습니다. 중요한 작업 전에는 현재 프로젝트 백업을 먼저 내려받습니다.

복원 시 기존 모델 파일을 일괄 삭제하지 않습니다. 같은 모델 ID가 서로 다른 GLB 내용을 가리키면 파일 덮어쓰기 대신 오류를 표시합니다.

골목에는 별도의 초안/공개본 단계가 없습니다. 서버에서는 골목 저장이 공개 지도에 반영됩니다. GPS 이동 기록은 이 프로젝트 ZIP 백업 대상이 아닙니다.

## 공개 지도와 서버 연결

- Vite 공개 지도 주소는 `http://127.0.0.1:5173/`입니다. 같은 브라우저의 확정한 건물 공개본·현재 골목·사용자 모델을 읽습니다.
- 서버 공개 지도는 `/api/map-buildings`, `/api/map-alleys`, `/api/map-models/<ID>`를 사용합니다.
- 로컬에서 **공개본 확정**을 눌러도 운영 서버로 업로드되지 않습니다. 서버 편집 앱의 **공개하기**가 서버 공개 단계입니다.
- 새 ZIP 정적 게시와 `snapshot` URL은 사용하지 않습니다. 과거 공개 ZIP을 로컬에서 복구하는 기능만 유지합니다.
- 로컬 ZIP을 서버로 직접 복원하거나 D1/R2 전체를 백업하는 기능은 별도 작업입니다.

## 작가님 공방

공방은 로드뷰로 만든 전용 모델이라 높이·색은 바뀌지 않지만, 다음은 고칠 수 있습니다. 지도에서 공방을 누르거나 **기존 건물 ID**에 `1468590644`를 넣어 고릅니다.

1. **위치·방향·크기**: 지도 위 이동·회전·크기 손잡이나 배치 값으로 맞춥니다. **원래 자리로**를 누르면 되돌립니다.
2. **3D 모델로 바꾸기**: 올린 GLB의 **이 모델로 바꾸기**를 누르면 모델이 공방 자리를 대신합니다. 모델을 지우면 원래 공방 모델로 돌아갑니다.
3. **장소 정보**: 이름·주소·설명·사진을 고칩니다. 비운 칸은 기본 정보를 씁니다. 사진은 브라우저에서 긴 변 1280px JPEG로 줄여 서버(R2 `map-images/`)에 올립니다(JPEG·PNG·WebP, 2MB까지). 개발 미리보기에서는 이 브라우저에만 저장합니다.

모두 건물 초안에 들어가고 **공개하기**를 눌러야 공개 지도에 나옵니다. 공개 지도의 공방 핀은 옮긴 자리나 바꾼 모델 자리를 따라갑니다.

## 서버 실행과 배포

명령은 저장소 루트에서 실행합니다.

```powershell
npm run export:site -- <홈페이지 저장소 경로>
```

지도는 별도 서버 없이 홈페이지 서버 안에서 돕니다. 위 명령으로 화면과 지도 API를 홈페이지에 넣은 뒤 홈페이지를 빌드·실행하면, 운영자 화면의 **지도 편집**(`/admin/map-editor`)에서 홈페이지의 로컬 DB·R2로 확인할 수 있습니다. 운영 배포는 홈페이지 배포와 같습니다.
