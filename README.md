# 감천 골목지도

감천2동의 가게와 명소를 표시하는 재사용 가능한 React 지도 컴포넌트입니다. 감천2동과 주변 일대를 사각형으로 표시하며 장소 검색·편집과 3D 에셋 배치 기능을 제공합니다. 실제 장소 데이터는 아직 연결하지 않았습니다.

## 개발 및 확인

```bash
npm install --legacy-peer-deps
npm run dev
```

브라우저에서 Vite가 출력하는 로컬 주소를 열면 미리보기 화면을 볼 수 있습니다. 미리보기의 감천문화마을 좌표는 UI 확인용 대략 위치입니다.

```bash
npm test
npm run build
```

`npm run build`는 다른 React 웹에서 사용할 수 있는 ES 모듈, CSS, 타입 선언, 기본 GLB 에셋을 `dist/`에 만듭니다. `dist/assets/models/` 디렉터리를 JS 파일과 함께 배포해야 기본 모델이 표시됩니다.

## 기존 React 웹에 연결

라이브러리 빌드 결과를 기존 웹의 패키지로 설치하거나 `src/`를 기존 프로젝트에 옮겨 사용할 수 있습니다. 컴포넌트를 담는 영역에 높이를 지정하세요.

```tsx
import { useState } from 'react'
import { GamcheonMap, type MapModel, type Place } from 'gamcheon-map'
import 'gamcheon-map/style.css'

const initialPlaces: Place[] = [
  {
    id: 'unique-place-id',
    name: '장소 이름',
    category: 'attraction', // 'attraction' 또는 'shop'
    latitude: 35.0975,
    longitude: 129.0103,
    address: '주소',
    description: '짧은 설명',
  },
]

export function MapSection() {
  const [places, setPlaces] = useState(initialPlaces)
  const [models, setModels] = useState<MapModel[]>([])

  return (
    <div style={{ height: 650 }}>
      <GamcheonMap
        places={places}
        editable
        onPlacesChange={setPlaces}
        onPlaceSelect={(place) => console.log(place)}
        models={models}
        onModelsChange={setModels}
      />
    </div>
  )
}
```

`places`가 비어 있으면 빈 상태가 표시됩니다. 표시된 사각형 영역 밖의 장소는 목록과 지도에서 숨깁니다. 검색은 이름·주소·설명을 대상으로 하며, 분류 버튼은 가게와 명소를 구분합니다. `editable`을 켜면 장소 추가·수정·삭제가 가능하고, 위치는 사각형 영역 안쪽의 지도를 클릭해 정합니다. 저장 결과는 `onPlacesChange`로 전달되므로 기존 웹의 서버나 데이터 저장소에 연결할 수 있습니다. 미리보기 화면에서는 브라우저의 로컬 저장소에 자동 저장됩니다.

## 3D 에셋 직접 배치

`editable`을 켜고 **3D 배치** 탭에서 **둥근형** 또는 **각진형** 모델을 고릅니다. **지도에 배치**를 누른 다음 사각형 지도 안쪽을 클릭하면 배치됩니다. 목록에서 모델을 선택하면 그 위치로 확대되고, 크기·회전·높이를 조절하거나 번호 표시를 드래그해 옮길 수 있습니다. **위치 변경**, **복제**, **삭제**도 가능합니다. **내 GLB 불러오기**로 20MB 이하의 `.glb` 파일을 추가할 수 있습니다. 사용자 GLB는 현재 브라우저의 IndexedDB에 저장됩니다.

배치 결과는 `onModelsChange`로 전달됩니다. 기존 웹에서 사용하려면 위 예시처럼 `models`를 상태로 관리하고, 지속 저장이 필요할 때는 서버나 데이터베이스에도 기록하세요. 미리보기는 배치 정보를 브라우저의 로컬 저장소에 저장합니다. 사용자 GLB는 같은 브라우저에서만 다시 열리므로 여러 기기에서 공유하려면 파일도 별도로 업로드·호스팅해야 합니다. GLB 모델의 좌표·크기는 편집 가능한 시연용이며 실제 건물 위치나 크기를 나타내지 않습니다.

기본 에셋 15개는 제공된 `all-6400` 폴더에서 골랐습니다. 모델 제작자는 **dogfooter**이며 자세한 사용 조건은 [`src/assets/models/LICENSE.txt`](src/assets/models/LICENSE.txt)에 있습니다. 기본 모델을 사용하는 화면에서도 제작자 표시를 유지하세요.

### 작가님 공방 모델

작가님 공방은 카카오맵 장소 **꿈꾸는작업실(부산 사하구 옥천로101번길 23, 감천동 12-299)**입니다. 거리 장면이 이 건물을 전용 모델(`src/artistWorkshopModel.ts`)로 직접 그립니다. 모델은 2025년 11월 장소 로드뷰를 기준으로 했고, 반영한 요소는 다음과 같습니다.

- 연한 베이지·회갈색 쪼갠면 벽돌
- 모서리를 감싸며 돌출된 알루미늄 통창: 골목 쪽 세 칸, 갈림길 쪽 한 칸
- 흰 양문과 문 위 등, 도로명 주소판, 콘크리트 계단참
- 옥상 테라스의 갓돌과 스테인리스 난간
- 통창 너머로 보이는 작업실 실내: 선반의 미술 재료, 벽에 건 캔버스, 작업대, 로드뷰에서 보이는 둥근 필름 릴 장식, 펜던트 조명(실내 배치는 추정)
- 골목 쪽 벽 끝의 빗물받이 관

지도에서 공방을 바로 찾을 수 있도록, 장소 표식은 "작가님 공방" 이름표가 달린 큰 표식으로 그리고 건물 둘레 바닥에 주황색 강조 띠를 둘렀습니다. 강조 띠는 지도 표시이며 실제 시설이 아닙니다.

지도 오른쪽 위 도구의 **작가님 공방만 보기** 버튼을 누르면 공방을 뺀 3D 건물을 모두 숨깁니다. 도로·바닥·나무·전신주와 장소 표식은 그대로 보이고, 숨긴 건물의 그림자도 함께 빠집니다. 한 번 더 누르면 다시 보입니다.

OSM 윤곽(1468590644)은 골목을 따라 9.5m×2.2m 띠로 그려져 있어 로드뷰에서 잰 크기(골목 쪽 약 4m, 갈림길 쪽 약 3.7m)로 나누었습니다. 띠의 나머지는 별도 부속 건물로 남겼습니다(`src/streetSceneData.ts`의 `splitWorkshopFootprint`). 높이와 보이지 않는 남쪽·동쪽 벽은 추정치입니다. `src/assets/models/custom/artist-workshop-180.glb`는 예전 GLB 시안으로, 3D 배치 탭에서 직접 배치할 때만 쓰입니다. 예전에 자동으로 넣었던 기본 배치는 겹치지 않도록 불러올 때 제외합니다.

기존 React 웹에서 같은 모델을 배치하려면 패키지에서 `ARTIST_WORKSHOP_MODEL`을 가져와 `models` 초기값에 넣으면 됩니다. 장소 검색에도 표시하려면 `ARTIST_WORKSHOP_PLACE`를 `places`에 추가하세요.

### 길찾기

패널의 **길찾기** 탭에서 걸어서 가는 길을 찾습니다. 보기 전용 지도에서도 쓸 수 있습니다.

- 출발지는 내 위치(GPS), 장소 목록, 지도에서 고른 곳 중에서 고릅니다. 도착지는 기본으로 작가님 공방입니다.
- 길 그물망은 OSM의 도로·골목·보도·계단 중심선(`src/street-surfaces.json`)과 직접 그린 골목길로 만듭니다(`src/routing.ts`). 화면용으로 위치를 보정한 도로가 아니라 OSM 원본을 씁니다.
- 걷는 속도는 평지 1.1m/s, 계단 0.55m/s로 잡았습니다. **계단 피하기**를 켜면 계단 없는 길만 찾습니다. 고도 자료가 없어 경사는 반영하지 않습니다.
- 지도를 열면 바로 내 위치(파란 점)와 바라보는 방향(화살표)을 보여 주고, 지도를 닫으면 추적을 멈춥니다. 방향은 휴대폰 나침반을 먼저 쓰고(iOS는 화면을 한 번 누를 때 권한을 물음), 없으면 걸어온 방향을 씁니다. 화살표는 매 프레임 부드럽게 돌아갑니다. 지도 도구의 **내 위치로 이동** 버튼으로 언제든 내 위치로 갈 수 있습니다. 위치는 화면에만 쓰고 저장하거나 보내지 않습니다. 경로에서 25m 넘게 벗어나면 현재 위치에서 다시 찾고, 목적지 15m 안에 들어오면 도착을 알립니다.
- 위치 기능은 HTTPS(또는 localhost)에서만 동작합니다. 권한이 거부되거나 위치가 지도 밖이면 장소·지도에서 출발지를 고르도록 안내합니다.

### 감천 작가 지도 홈페이지로 내보내기

감천 작가 지도 홈페이지(Next.js/vinext 저장소)는 이 지도를 두 곳에서 씁니다. `npm run export:site -- "<홈페이지 저장소 경로>"`를 실행하면 둘 다 새로 만들어 넣습니다.

- `public/artist-map-embed/`: 공개 작가 지도(`/map`)가 iframe으로 끼워 쓰는 지도입니다(`embed.html`, `src/embed.tsx`). 패널 없이 지도만 보이고, 부모 창과 `postMessage`로 장소 목록·선택(`set`)을 받고 선택(`select`)·지도에서 고른 좌표(`pick`)를 보냅니다.
- `public/admin-art-map/assets/`: 관리자 골목지도 작업실(`/admin/art-map`)이 쓰는 편집용 지도입니다(`index.html`, `src/demo.tsx`). 관리자 페이지가 고정 이름(`map.js`, `map.css`)으로 불러옵니다.
- 관리자 페이지의 `Bundled from ... at <커밋>` 표시도 현재 커밋으로 갱신합니다.

내보낸 뒤 홈페이지 저장소에서 빌드·배포해야 운영 사이트에 반영됩니다.

### 성능

- 도로·보도 면(수천 개의 도로 조각을 합치고 건물 자리를 빼는 계산)은 `npm run build:road-ground`로 미리 계산해 `src/generated/road-ground.json`에 저장합니다. 지도 자료(`src/gamcheon-buildings.json`, `src/street-surfaces.json`)나 도로·건물 계산 코드를 고치면 이 명령을 다시 실행하세요. 입력이 바뀌었는데 저장본이 그대로면 `src/roadGround.test.ts`가 실패해 알려 줍니다.
- 바탕 지도를 먼저 그린 뒤 3D 거리를 만들고, 그동안 "3D 거리를 불러오는 중" 안내를 보여 줍니다. 거리에서 75m 넘게 떨어진 건물은 지도에 붙은 뒤 12ms 단위로 나눠 만들어 화면이 멈추지 않게 합니다.
- 측정값(개발 PC): 첫 화면을 막는 장면 만들기 시간이 Node에서 17.6초 → 3.5초, 브라우저에서 약 2.2초입니다. 먼 동네 건물은 그 뒤 약 2.8초에 걸쳐 나눠 채워집니다. 브라우저에서는 `performance.getEntriesByName('gamcheon-map:street-scene-build')`와 `'gamcheon-map:district-build'`로 확인할 수 있습니다.
- 성능 예산: `src/streetScenePerformance.test.ts`가 첫 화면 장면 만들기를 9초 안으로 묶어 큰 퇴보를 잡습니다.
- 휴대폰에서 그래픽(WebGL) 연결이 끊기면 안내를 띄우고, 다시 연결되면 3D 층을 자동으로 붙입니다.

### 촬영 거리 3D 장면

첫 화면과 오른쪽 위 **촬영 거리 보기**는 카페아뽕 인근에서 작가님 공방까지의 약 130m 구간을 기울인 시점으로 보여줍니다. 이는 이동 경로 안내가 아니라 지도 위 거리 장면입니다. 도로의 위치와 굽은 형태는 OSM의 옥천로75번길·감내1로 노드(`src/streetSceneData.ts`)를, 양옆 건물 위치와 외곽은 저장된 OSM 건물 윤곽(`src/gamcheon-buildings.json`)을 사용합니다. 사용자가 제공한 2026년 9월 촬영 영상을 따라 남쪽의 붉은 벽돌·크림색 상가, 중간의 청록·하늘색 외벽, 북쪽 굽은 길의 녹색·분홍색 건물이 나타나도록 구간별 외관을 다르게 표현했습니다. 회청색 블록 포장, 노란 가장자리 선, 원형 포장 무늬, 일부 주차 차량과 전신주도 간략한 3D 형태로 표현했습니다. 공방은 거리 장면 안의 전용 모델로 표시합니다.

거리 건물에는 영상에서 보이는 평지붕과 일부 경사지붕, 유리 상점 전면·셔터·줄무늬 차양·벽돌 줄눈을 단순화해 적용했습니다. 공방과 시각적 밀도를 맞추기 위해 창틀·창턱·출입문·손잡이·건물 기단·층간 띠·옥상 설비와 일부 난간도 더했습니다. 조감도의 에스컬레이터나 새 건축물은 실제 촬영 거리의 현황으로 확인되지 않아 배치하지 않았습니다. 건물 높이와 촬영되지 않은 면은 실측값이 없어 추정치입니다. `src/streetSceneData.ts`에서 건물별 색과 높이 규칙을, `src/StreetSceneLayer.ts`에서 창·차양·포장 표현을 수정할 수 있습니다. 3D 배치 탭의 사용자 GLB와 장소 정보는 기존 방식대로 지도에서 직접 편집됩니다. 거리 건물 자체는 현재 코드 기반 장면으로, 지도 UI에서 개별 건물의 외관을 수정하는 기능은 아직 제공하지 않습니다.

촬영 영상에서 외관을 식별할 수 있는 추가 건물 19동은 OSM 건물 ID별로 외벽색, 1층 유리창·셔터, 차양, 상층 창 배열을 지정했습니다. 적용한 프레임과 확인 범위는 [`design/building-observation-log.md`](design/building-observation-log.md)에 기록했습니다. 영상에 GPS가 없으므로 프레임과 각 OSM 건물의 대응은 잠정적이며, 영상에서 보이지 않는 나머지 건물은 여전히 구역별 추정 모델입니다.

조사하지 않은 건물의 지붕은 감천 산비탈 마을에 흔한 청색·청록·녹색 칠 금속 지붕과 회색 슬래브 지붕을 섞은 일반형 디자인 팔레트(`src/streetSceneData.ts`의 `genericRoof`)로 칠합니다. 항공사진 등 건물별 자료에서 얻은 색이 아니며, OSM 번호로 골라 건물마다 늘 같은 색이 됩니다. 사진 시안 6동과 현장 사진으로 확인한 카페아봉은 기존 지붕색을 유지합니다. 맞붙은 벽에는 창문을 생략했습니다. 로드뷰로 확인하지 않은 개별 외벽색·재질·상점 전면·발코니를 임의 지정했던 24동 시안은 제거했습니다. 공방 북쪽 남북 도로 양옆의 4동은 2025년 11월 로드뷰와 도로·건물 윤곽을 대조해 흰 미장·적벽돌·황토색 미장 외관을 적용했습니다. 나머지 미확인 외벽은 중립색 임시 모델이며, 개별 외관은 주소와 촬영면을 대조한 뒤 추가해야 합니다. 조사 근거는 [`design/expanded-area-source-notes.md`](design/expanded-area-source-notes.md)에 기록했습니다.

### 지도 전체 3D 범위

공방 북쪽 로드뷰의 흰 미장 건물은 곡면 청록 차양·넓은 창을, 맞은편 적벽돌 건물은 하층 셔터와 유리 출입부를 보완했습니다. 전체 건물의 개별 외벽 대조는 아직 완료되지 않았습니다.

촬영 거리의 선택 범위를 없애고 현재 사각 지도 전체의 OSM 건물 윤곽 2천여 동을 3D로 표시합니다. **전체 지도 보기** 버튼으로 넓은 범위를 볼 수 있습니다. 도로·골목 636개와 녹지 14곳을 같은 사각 범위에서 받아 바닥에 적용했습니다. 도로 면은 작은 단위로 합치고 좌표를 밀리미터 단위로 정리해 교차부의 계산 오류를 줄이며, 건물 윤곽을 도로에서 제외합니다. `node scripts/fetch-map-surfaces.mjs`로 도로·녹지 사본을 갱신할 수 있습니다.

공방과 조사한 거리 건물은 기존 상세 모델을 유지합니다. 멀리 있는 건물은 창틀·창턱·기단·층간 띠·옥상 테두리를 묶어 그리는 모델을 사용합니다. 전체 건물의 실제 외벽을 로드뷰로 확인한 것은 아니며, 미확인 외벽은 중립색, 지붕은 일반형 팔레트입니다. 건물 높이와 도로 폭은 자료가 없는 경우 추정치이고 지형 높낮이는 아직 평면입니다.

## 골목길 직접 그리기

`editable`을 켜고 **골목길** 탭에서 **새 골목길 그리기**를 누른 뒤 지도를 차례로 클릭해 점을 찍고 **완료**를 누릅니다. 목록에서 골목길을 고르면 흰 점을 드래그해 모양을 고치거나, 점을 더블클릭해 지우거나, 점 사이의 ＋를 눌러 점을 추가할 수 있습니다. 이름과 폭(1~8m)도 바꿀 수 있습니다. 3D 모델은 현재 카메라 각도에서 도로·골목길을 가리면 그 모델만 자동으로 반투명해집니다. 모델이 화면에서 차지하는 영역을 계산해 그 안을 지나는 길이 있는지 카메라가 움직일 때마다 다시 판정합니다. 골목길 탭에서는 모든 모델이 반투명해지며, 다른 탭에서도 지도 오른쪽 위의 상자 버튼으로 모두 반투명하게 볼 수 있습니다. 폭은 기본값 3m가 배경지도의 골목과 같은 굵기가 되도록 비례해 그리므로 실제 치수가 아닌 상대적인 굵기입니다.

그린 결과는 `alleys` / `onAlleysChange`로 주고받으며 형식은 `Alley` 타입(`{ id, name?, coordinates: [경도, 위도][], widthMeters }`)입니다. 미리보기는 브라우저의 로컬 저장소에 저장합니다.

## 실제 건물 윤곽

지도 오른쪽 위의 건물 버튼으로 OpenStreetMap 건물 외곽선을 켜고 끌 수 있습니다. 벡터 타일의 건물은 일부 줌에만 들어 있어 표시 영역의 건물을 `src/gamcheon-buildings.json`에 저장해 사용합니다. `node scripts/fetch-buildings.mjs`로 다시 받을 수 있습니다.

## 지도 데이터

배경지도는 OpenStreetMap 데이터를 사용하는 [OpenFreeMap Positron 벡터 스타일](https://openfreemap.org/quick_start/)을 바탕으로 합니다. 크림색 바탕, 녹색 공원·숲, 청록색 물, 밝은 도로와 따뜻한 윤곽선으로 색을 조정했습니다. 건물과 기본 지도 글자 레이어는 숨기고 도로·공원·물길은 남겼습니다. [OpenStreetMap 감천2동 경계(Relation 4057099)](https://www.openstreetmap.org/relation/4057099)를 `src/gamcheon2-boundary.json`에 저장하고, 해당 경계의 최소·최대 좌표에서 사방으로 넓힌 사각형을 표시 영역으로 사용합니다. 사각형 밖은 단색으로 가리고 지도 이동 범위도 주변으로 제한합니다. 경계 데이터는 저장 시점의 사본이므로 OpenStreetMap에서 바뀌어도 자동 갱신되지 않습니다. 지도 바닥은 평면이며 시점을 기울이거나 회전해 볼 수 있습니다. 마우스 휠로 확대·축소하고, 마우스 오른쪽 버튼을 누른 채 움직여 시점을 회전하거나 기울일 수 있습니다. 출처 표기는 지도 오른쪽 아래에 유지합니다. `src/positron-style.json`은 OpenFreeMap 스타일을 가져온 파일이며, OpenFreeMap 프로젝트의 라이선스는 [공식 사이트](https://openfreemap.org/)에 안내되어 있습니다.
